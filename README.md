---

## 📌 Features Included

1. **Accessible Modal Dialog System**
   - Focus trapping inside modal container when open.
   - Escape key dismiss listener & backdrop click handler.
   - `role="dialog"` & `aria-modal="true"` accessibility attributes.

2. **Animated Accordion Component**
   - Smooth CSS `max-height` transitions.
   - Dynamic `aria-expanded` and `hidden` attribute synchronization.
   - Up/Down Arrow keyboard navigation between headers.

3. **Dynamic Tabbed Panel System**
   - Left/Right Arrow keyboard switching.
   - W3C ARIA tab roles (`role="tablist"`, `role="tab"`, `role="tabpanel"`).
   - Animated active tab indicator and panel transition.

4. **Toast Notification Manager**
   - Dynamic alert spawning with custom status levels (Success, Warning, Error).
   - Auto-dismiss timer (4s) and manual dismiss controls.
   - `role="status"` live region support.
